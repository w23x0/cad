# 11_sector_ring — 300° 开口环形扇体（C 形环）

## 设计意图

矩形截面（径向 10..20，z −5..5）绕 Z 轴旋转 300° 的开口环。特征：**部分角旋转**
（非整圈 Pappus）、旋转体两端为平面（0° 与 300° 径向端面）。

## 体积手算（角度比例 Pappus）

整圈环 V_full = π(R²−r²)·h = π·300·10 = 3000π；300° 占 5/6：

V = 2500π = **7853.981633974483** mm³

## 质心手算（环形扇 centroid 公式）

- 径向质心：r̄ = (2/3)·(R³−r³)/(R²−r²)·sin(θ/2)/(θ/2)，θ = 300°
  = (2/3)·(7000/300)·(0.5/2.617994) = 2.970892271048712
- 方位：扇区中角 150° → COM = r̄·(cos150°, sin150°)
  = (−2.572868178635029, 1.4854461355243558, 0)

## bbox / 拓扑

扇区含 0°/90°/180°/270° 方向 → bbox = [40, 40, 10]；solids = 1，valid = true。

## 容差说明

build123d 体积/质心与解析值逐位一致。smlibpy 部分角旋转体积实测差 ~4.5e-7（相对），
贴近但未超 1e-6 契约；若质心超 1e-6 绝对差，按契约规则在 expected.json 放宽
centroid_abs 并记录原因（部分角旋转的端面生成方式差异），体积容差不放宽。

## 构建顺序（两内核一致）

`Polygon((10,−5),(20,−5),(20,5),(10,5))` 置于 Plane.XZ（局部 x=半径，y=高度），
`revolve(sec, Axis.Z, 300)`。
