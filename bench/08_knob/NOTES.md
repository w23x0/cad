# 08_knob — 曲面基元件（圆锥台 + 半球 + 穿孔 + 独立 O 圈）

## 设计意图

旋钮 + 配套 O 圈的套件布置，覆盖圆锥台、球、环面三种二次曲面基元。
solids = 2（旋钮本体 + 旁边独立平放的 O 圈，不相交融合）。

> **v1 → v2 变更记录（内核发现）**：v1 曾把环面作为"中心圆恰在圆柱侧面柱面上"
> 的鼓圈与圆柱做横穿并集——smlibpy 0.3.3 返回错误结果（把环面误判为包含圆柱：
> 并集=环面本尊、交集=圆柱本尊、切割=空体），build123d 精确正确，2 亿点蒙特卡洛
> 仲裁（误差 ±1 mm³）确认解析值 = build123d。详见 `harness/FINDINGS.md`。
> v2 把环面改为与本体**不相交**的独立 O 圈（不相交融合在两内核均已验证精确），
> 环面基元仍被覆盖，但避开坏的布尔路径。

## 尺寸

- 底圆柱：R20 × 8，z ∈ [0, 8]
- 圆锥台：底 r12 → 顶 r9 × 高 12，z ∈ [8, 20]，底面落在圆柱顶面上（环形接触融合）
- 球：r8，球心 (0, 0, 20) 在锥台顶面上；下半球完全含于锥台内（锥台半径在
  z∈[12,20] 恒 ≥ 9 > 球截面半径），并集只增加上半球
- 4× Ø4 轴向穿孔：中心分布在 R15 圆上（90° 间隔），孔范围 r 13..17：
  完全在底柱内（< 20），完全避开锥台足迹（> 12），穿透上下两面
- O 圈：环面 R10 / 管 r2，轴 Z，中心 (34, 0, 2)，z ∈ [0, 4]；
  内缘 34−12 = 22 > 20，与本体间隙 2 mm，不相交

## 体积手算

- 底圆柱 π·20²·8 = 3 200π
- 圆锥台 π·12/3·(12² + 12·9 + 9²) = 4π·333 = 1 332π
- 上半球 (2/3)π·8³ = 1 024π/3
- 4 孔 −4·π·2²·8 = −128π
- O 圈（完整环面）2π²·R·r² = 2π²·10·4 = 80π²

V = (3 200 + 1 332 − 128)π + 1 024π/3 + 80π² = 4 404π + 1 024π/3 + 80π²
  = 15 697.472690921913 mm³

## bbox / 拓扑

- X：本体 −20..20，O 圈 22..46 → 66
- Y：±20（O 圈 ±12 更小）→ 40
- Z：0..28（球顶）
- solids = 2，valid = true

## 构建顺序（两内核一致）

1. `Cylinder(20,8)` 移 z 0..8
2. `+ Cone(12,9,12)` 移 z 8..20
3. `+ Sphere(8)` 移 (0,0,20)
4. `+ Torus(10,2)` 移 (34, 0, 2)
5. `−= PolarLocations(15, 4) * Cylinder(2, 10)` 移 z 4（工具 z −1..9，只穿透底柱）

## 容差

默认 1e-6。两内核图元 API 实测逐位一致；所用布尔路径（接触融合、不相交融合、
穿透切割）均已验证精确。

## 质心手算

质心：旋钮轴对称 x=y=0；半球质心 z=20+3r/8=23；O 圈@(34,0,2) → x=34·80π²/V=1.710169，y=0，z：圆锥台质心不在半高，为 h(r1²+2r1r2+3r2²)/(4(r1²+r1r2+r2²))，即 z=8+12·603/1332=13.432432；半球质心 z=20+3r/8=23；z=(3200π·4+1332π·13.432432+(1024π/3)·23+80π²·2−128π·4)/V=7.711815。（初版手算误把圆台质心放在半高得 7.863116，双内核一致地否决——契约起了作用。）
