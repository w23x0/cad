# 09_loft_transition — 方→矩 ruled 放样（棱台体）

## 设计意图

40×40 方形截面 → 20×30 矩形截面的直纹放样（ruled loft），两截面平行且角点对应
（两个 Polyline 都从 +X+Y 角出发同向绕行，避免 docs 警告的"拧转放样"）。
特征：loft、非相似截面的精确真值（prismatoid 公式）。

## 尺寸

- 下截面：40 × 40，z = −8
- 上截面：20 × 30，z = +8（x 向 40→20，y 向 40→30）
- 段高 h = 16

## 体积手算（prismatoid 公式，对任意双平行多边形顶盖精确）

- A1 = 1600，A2 = 600，中位截面角点取平均 → 30 × 35 = Am = 1050
- V = h/6·(A1 + 4Am + A2) = 16/6·(1600 + 4200 + 600) = 16/6·6400 = **51200/3 = 17066.666666666667**

## 质心手算

- 截面积 A(t) = (40−20t)(40−10t) = 1600 − 1200t + 200t²，t ∈ [0,1] 自下而上
- ∫A dt = 3200/3；∫tA dt = 800 − 400 + 50 = 450
- z̄ = −8 + 16·450/(3200/3) = −8 + 6.75 = **−1.25**；x̄ = 0（每层关于 x 对称），ȳ = 0

## bbox / 拓扑

- bbox = [40, 40, 16]；solids = 1，valid = true

## 容差

默认 1e-6。两内核 ruled loft 探针实测逐位一致（17066.66666666667 / 17066.666666666668）。
