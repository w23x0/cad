# 20_taper_ring — 带孔锥度挤出（环类锥度）

## 设计意图

外 Ø20 / 内 Ø10 圆环截面沿 Z 挤出 10、锥度 5°：外锥收窄、内孔**反向扩宽**
（taper 对孔的镜像语义）。特征：带内环的锥度挤出、线性 A(t) 的优雅真值。

## 体积手算

a = tan5°。外锥 R: 10 → 10−10a；内孔 r: 5 → 5+10a：

V = π·10/3·[(10² + 10R₂ + R₂²) − (5² + 5r₂ + r₂²)]
  = π·10/3·[(100 + 91.25113 + 83.26831) − (25 + 29.37443 + 34.51336)]
  = π·10/3·185.63145 = **1 943.9138762841962** mm³

## 质心手算

A(t) = π[(10−10at)² − (5+10at)²] = π(75 − 300at) —— 二次项相消，A(t) 严格线性
（但线性 ≠ 常数！）：z̄ = h·(A₀/2 + k/3)/(A₀ + k/2)，k = −300a
= 10·(37.5 − 100a)/(75 − 150a) = **4.646519749257152**；x = y = 0（轴对称）。
（初版误以为线性 A(t) ⇒ 质心 h/2，两内核一致否决——契约第 6 次纠正手算。）

## bbox / 拓扑

bbox = [20, 20, 10]；solids = 1，valid = true。

## 容差

默认 1e-6。两内核实测 1943.9138762857817 / 1943.9138762841962（相对差 8e-13），
与手算公式逐位吻合。
