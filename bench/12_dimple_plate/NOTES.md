# 12_dimple_plate — 半球凹坑板

## 设计意图

100×60×10 板顶面三个半球凹坑（球心恰在顶面 z=+5 上，穿透式曲面切割——工具越过
表面，去除体恰为半球）。特征：曲面（球）切割、非对称布置的真值。

## 尺寸

- 板：100 (X) × 60 (Y) × 10 (Z)，居中（z ∈ [−5, 5]）
- 凹坑 A：r8 @ (−30, 0, 5)；B：r6 @ (0, −12, 5)；C：r5 @ (10, 14, 5)
- 间距检查：A–C 42.4 > 13，B–C 27.9 > 11，A–B 32.3 > 14；脚印均在板内

## 体积手算

去除 = 三个半球 Σ(2/3)πr³ = (2/3)π·(512+216+125) = 1706π/3

V = 60 000 − 1706π/3 = **58 213.480977658604** mm³

## 质心手算

板质心 (0,0,0)；去除半球质心在球心下方 3r/8（z = 5−3r/8 → 2.0 / 2.75 / 3.125）：

- x = (30·V_A − 10·V_C)/V = 0.5076472734229642（A 在 −30 被去除 → 质心右移为主）
- y = (12·V_B − 14·V_C)/V = 0.03029333835734485
- z = −(2·V_A + 2.75·V_B + 3.125·V_C)/V = −0.07226598189788813

## bbox / 拓扑

bbox = [100, 60, 10]（凹坑不产生材料）；solids = 1，valid = true。

## 容差

默认 1e-6。半球凹坑切割在两内核探针实测精确（去除量逐位一致）。
