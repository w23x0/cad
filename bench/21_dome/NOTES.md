# 21_dome — 球冠截体（平面截球）

## 设计意图

R15 球被平面 z=5 截去顶冠（冠高 10），保留下部。特征：**曲面体平面剖分**、
球冠公式的干净整值真值。

## 体积手算

V = V_sphere − V_cap = (4/3)π·15³ − π·10²·(3·15−10)/3 = 4500π − 3500π/3
  = 10 000π/3 = **10 471.975511965977** mm³

## 质心手算

V·z̄ = ∫₋₁₅⁵ z·π(225−z²)dz = π[112.5z² − z⁴/4]₋₁₅⁵ = π(2656.25 − 12656.25) = −10 000π

z̄ = −10 000π/(10 000π/3) = **−3.0** 精确；x = y = 0（轴对称）。

## bbox / 拓扑

bbox = [30, 30, 20]；solids = 1，faces = 2（球面 + 顶平面），valid = true
（faces=2 写入 engine_metrics，两内核一致）。

## 容差

默认 1e-6。两内核探针逐位一致（10471.97551196598 / 10471.975511965982）。
