# 31 float_ring — 浮球 + 阀座环（不相交装配）

## 设计意图

浮球与绕其赤道的阀座环，两实体不相交融合（净隙 2 mm）。覆盖：
同心嵌套 AABB 的不相交融合（FZ-8 触发面探针）、球/环面基元、
多实体 interference 指标（measure.py 对 ≥2 实体自动算两两交集）。

## 尺寸

- 球：r10，球心原点
- 环：Torus(R16, r4)，轴 Z，中心圆在 z=0 平面（ρ ∈ [12, 20]，z ∈ [−4, 4]）
- 间隙：环内缘 ρ = 16−4 = 12 > 球半径 10 → 净隙 2 mm，不相交

## 探针结论

1. **FZ-8（smlibpy 并集丢 cell：两体不相交 + AABB 三轴交错）在此几何未触发**：
   球 AABB [−10,10]³ 与环 AABB（x,y ±20、z ±4）三轴交错且实体不相交，但
   `Sphere(10) + Torus(16,4)` 两内核均体积精确、solids=2、valid=true。
   对照 fuzz/FINDINGS.md：FZ-8 已知触发需要 ≥3 体融合链（pre 已成 2-cell
   再加第三体时丢 cell），纯两体不相交并集安全。
2. 两内核 Torus 默认均为轴 Z、中心圆在 XY 平面（08 号 O 圈同款语义）。

## 体积手算

- 球 (4/3)·π·10³ = 4000π/3
- 环 2π²·R·r² = 2π²·16·16 = 512π²

V = **4000π/3 + 512π² = 9242.027658144143 mm³**

## 质心手算

球心在原点；环关于 z=0 平面与 XY 平面对称 → **(0, 0, 0)**。

## bbox / 拓扑

- X/Y：环 ±20（球 ±10 更小）→ 40；Z：球 ±10（环 ±4 更小）→ 20 → [40, 40, 20]
- solids = 2，valid = true
- faces = 2（球面 + 环面，各 1 个闭合曲面，无平面）
- interference_mm3 = 0（不相交）

## 容差

默认 1e-6。两内核体积逐位一致，无需放宽。
