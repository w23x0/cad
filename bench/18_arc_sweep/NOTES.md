# 18_arc_sweep — 沿弧扫掠（270° 部分圆环体）

## 设计意图

Ø10 圆截面沿 R20 圆弧扫掠 270°，得四分之三圆环体（C 形 O 圈）。
特征：**sweep 沿曲线路径**、扫掠体精确真值（部分环面）、两内核 sweep
放置语义差异（F-9）。

> **F-9 sweep 放置语义差**：smlibpy 自动把截面包围盒中心搬到路径起点并转向；
> build123d 要求截面**已放在路径起点且垂直于起始切线**，否则静默返回空壳
> （vol=0、faces=1、valid=True、不报错）。模型文件里两内核写法不同即源于此。

## 体积手算

扫掠体体积 = φ_total·A·R（截面质心走弧长，Pappus 扫掠形式），A = π·5²，φ = 3π/2：

V = (3π/2)·25π·20 = 750π² = **7402.203300817018** mm³

## 质心手算

位置向量 = ∫∫ρ²dρdz·(∫e(φ)dφ)/V；∫e dφ（φ∈[0,3π/2]）= (−1, 1)；
∫∫ρ²dρdz = A·R² + πr⁴/4 = π(25·400 + 625/4) = 10 156.25π：

x = −10 156.25π/(750π²) = −10 156.25/(750π) = **−4.3104463754054985**
y = +4.3104463754054985，z = 0

（注：初版"ρ̄=R+r²/4R 置于中角"是错的——角向加权让幅值再乘 |∫e dφ|/φ_total。
smlibpy 实测质心与正确公式逐位一致。）

## bbox / 拓扑

扇区含 0°/90°/180°/270° → bbox = [50, 50, 10]；solids = 1，faces = 3
（环面面 + 两平端盖），valid = true。

## 容差（本件唯一放宽：bbox_abs = 1e-5）

smlibpy 的扫掠环面面是近似曲面：体积 7402.203257（相对差 5.9e-9，远小于体积
契约），但 bbox Z = 10.000005（偏差 5e-6），超出默认 bbox_abs=1e-6。b123d 环面
为精确解析面。故本件 bbox_abs 放宽到 1e-5（放大 10 倍，仍极严），体积与质心
容差保持默认。原因：smlibpy sweep 输出 NURBS 近似面而非解析环面。
