# 19_cone_pocket_plate — 锥孔板（沉孔式锥切）

## 设计意图

80×40×10 板顶面中央锥形沉孔：Cone(r 4→9, h 10) 从 z=0 切到 z=10，与板相交
z ∈ [0,5]，孔底半径 4、板面开口半径 6.5。特征：**圆锥面切割**（安全路径）、
变半径孔的精确积分真值。

## 体积手算

锥半径 r(z) = 4 + z/2（z 0..10；板内 z 0..5）。去除：

∫₀⁵ π(4+z/2)²dz = π·(16z + 2z² + z³/12)|₀⁵ = π·140.416667 = 1685π/12

V = 32 000 − 1685π/12 = **31 558.86803155843** mm³

## 质心手算

去除体质心 z = ∫₀⁵ z·r²dz/∫₀⁵r²dz = (200 + 500/3 + 625/16)/140.416667
= 405.729167/140.416667 = 2.889267（x=y=0 对称）：

z = −(2.889267·441.131968)/V = **−0.040389055549235064**
（初版把 z⁴/16 项误写成 625/48，两内核一致否决——契约第 5 次纠正手算。）

## bbox / 拓扑

bbox = [80, 40, 10]；solids = 1，faces = 8（板 6 面 + 锥面，顶/底面带孔），valid = true。

## 容差

默认 1e-6。两内核探针体积逐位一致（31558.868031558435 / 31558.86803155843）。
