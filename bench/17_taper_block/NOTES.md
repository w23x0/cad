# 17_taper_block — 锥度挤出（棱台体真值）

## 设计意图

40×30 矩形截面沿 Z 挤出 20、锥度 10°（正向收窄）。特征：**taper extrude**、
非相似端面的精确真值（棱台体/辛普森公式，**不是**棱锥台公式——初版推导用错
公式被两内核一致否决，见下）。

> 真值公式注记：两端面积不相似（长宽收窄量相同、比例不同），侧面为平面梯形
> （实测面积 740.7224 / 537.6371 与梯形公式逐位一致），故体积用棱台体公式
> V = h/6·(A0 + 4Am + A1)，Am 为中位截面。棱锥台公式 h/3(A0+A1+√(A0A1)) 只适用
> 于相似端面（圆锥已单独验证：Circle taper 与圆锥台公式逐位吻合）。

## 体积手算

- 收窄率：每侧 z·tan10°；A0 = 1200，A1 = (40−40tan10°)(30−40tan10°) = 756.0303806175195
- Am = (40−20tan10°)(30−20tan10°) = 965.5787086584542（与两内核中位截面实测一致）
- V = 20/6·(1200 + 4·965.5787086584542 + 756.0303806175195)
  = **19 394.484050837793** mm³

## 质心手算

A(t) = (40−40at)(30−40at)（t∈[0,1]，每侧收窄 z·a = 20t·a），a = tan10°：
∫A dt = 1200 − 1400a + (1600/3)a² = 969.724（= 棱台体公式核验一致），
∫tA dt = 600 − (2800/3)a + 400a²；z̄ = 20·∫tA/∫A = **9.236948646122398**；x = y = 0。
（初版积分把收窄项少乘因子 2 得 9.965534，两内核一致否决——契约再次纠正手算。）

## bbox / 拓扑

bbox = [40, 30, 20]；solids = 1，faces = 6，valid = true。

## 容差

默认 1e-6。两内核探针体积逐位一致（19394.48405083779 / 19394.484050837793），
顶面面积、中位截面、侧面梯形面积全部与公式吻合。
