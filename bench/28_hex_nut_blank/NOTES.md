# 28 hex_nut_blank — 六角螺母坯

## 设计意图

六角棱柱（对边距 24）挤出高 10，中心 Ø12 贯穿孔。特征：RegularPolygon
草图的跨内核相位语义、穿透孔工具的正确放置。

## 尺寸

- 六边形：对边距（across flats）24 → 内切圆半径（apothem）r = 12，
  外接圆半径（角距）R = 12/cos30° = 24/√3 = 8√3 ≈ 13.8564
- 挤出 z 0..10，孔 Ø12（r6）贯穿

## RegularPolygon 相位探针结论（语义发现）

两内核在 rotation=0 时相位**完全一致**，无需对齐：
- smlibpy `RegularPolygon(12, 6, inscribed=True)` 顶点（打印实测）：
  (±13.856406, 0), (±6.928203, ±12) —— 首角在 +X，flat 在 y=±12
- b123d `RegularPolygon(12, 6, major_radius=False)` 顶点：逐位相同
- 即：**两内核都把第一个顶点放在 +X**（文档明说 smlibpy；b123d 探针证实），
  bbox 均为 2R × 2r = 27.712812921102035 × 24
- 参数名差异（同义不同名）：smlibpy 用 `inscribed=True` 表示"半径是内切圆
  半径"；b123d 用 `major_radius=False` 表示同一件事。默认（False/缺省）两者
  都指外接圆半径。
- 体积对相位天然不变（旋转对称），但 bbox 会变——本件因相位一致而直接可比；
  若未来某内核改相位，bbox 检查会立即暴露。

## 穿透工具放置（两内核同款陷阱）

棱柱在 z 0..10，而居中的 `Cylinder(6, 12)` 跨 z −6..6，只能切掉孔的
z 0..6 段：两内核都静默接受，体积 4988.31 − 678.58 = 4309.72（探针实测，
两边一致地错）。工具必须 `Pos(0,0,5) * Cylinder(6, 12)`（跨 −1..11），
符合 F-1 安全路径"工具越过被切面"。居中坯（如 03_flange 的 z 对称板）
不会有此问题——非对称放置的坯才暴露。

## 体积手算

正六边形面积（apothem r=12）：A = n·r²·tan(π/n) = 6·144·tan30° = 864/√3
= 288√3 ≈ 498.8306325798366（等价地 3√3·R²/2，R = 8√3）
孔面积 π·6² = 36π ≈ 113.09733552923255
V = (288√3 − 36π)·10 = 2880√3 − 360π = **3857.3329705060405** mm³

（简报公式 216√3 用的是外接圆半径 r=12 的正六边形；本件 24 是对边距，
apothem=12、R=8√3，代入同一公式得 288√3，两者自洽。）

## 质心手算

六边形（角在 ±X、flat 在 y=±12）与孔均对称于 X/Y 轴，z 0..10 → (0, 0, 5)。

## bbox / 拓扑

- bbox = [16√3, 24, 10] = [27.712812921102035, 24, 10]
- solids = 1，valid = true
- faces = 9（六侧面 + 上下环形端面 + 孔柱面）——两内核一致

## 容差

默认 1e-6。两内核实测体积与手算逐位一致（rel ≤ 2.4e-16）。
