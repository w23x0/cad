# 13_cavity_block — 封闭内腔块（球腔 + 环面腔）

## 设计意图

40×40×30 方块内部两个**完全封闭**的空腔：左球腔（r9 @ (−10,0,0)）、右环面腔
（R6 r2，轴 Z，@ (10,0,0)）。特征：内部空腔拓扑（B-rep 外壳 + 内壳，多壳边界）、
完全内含工具的切割（booleans.md 文档路径，实测精确）。渲染图看不见内腔——
本件靠 volume/centroid/faces 三个指标闭环。

## 尺寸与包含检查

- 方块：40 (X) × 40 (Y) × 30 (Z)，居中
- 球腔 r9 @ (−10,0,0)：x −19..−1 ⊂ [−20,20] ✓
- 环面腔 R6 r2 @ (10,0,0)：x 2..18 ✓，y ±8 ✓，z ±2 ✓
- 两腔不相交（球 x≤−1，环面 x≥2）✓

## 体积手算

V = 40·40·30 − (4/3)π·9³ − 2π²·6·2² = 48 000 − 972π − 48π²
  = **44 472.63092945843** mm³

## 质心手算

方块对称；空腔去除使质心偏离被挖材料：

x = −(972π·(−10) + 48π²·10)/V = (9720π − 480π²)/V = **0.5801066845200037**，y = z = 0

## bbox / 拓扑

- bbox = [40, 40, 30]（内腔不改变外形）
- solids = 1，valid = true
- faces = 8（盒 6 面 + 球内壳 1 + 环面内壳 1）——两内核一致，写入 engine_metrics

## 容差

默认 1e-6。两内核探针实测：体积逐位一致（44472.63092945843 / 44472.630929458464），
faces 同为 8，质心一致。
