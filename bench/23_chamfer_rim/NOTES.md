# 23_chamfer_rim — 孔口倒角（圆边上的 chamfer）

## 设计意图

80×40×10 板开 Ø20 通孔，孔顶口倒角 2（45° 对称倒角，倒角面为精确圆锥面段）。
特征：**圆边 chamfer**（对偶于 22 的圆边 fillet）、按几何属性选圆边、去除体的
Pappus 真值与 ρ 加权质心（沿用 22 的教训）。

## 体积手算

去除区截面是 (r, d) 平面（d = 距顶面深度）里的直角三角形，顶点 (10,0)、(12,0)、(10,2)：
顶面开口扩到 r=12，深 2 处收到 r=10 接通孔壁。A = 2，形心 r̄ = (10+12+10)/3 = 32/3。
Pappus：V_去除 = 2π·(32/3)·2 = 128π/3 = 134.04128655316455 mm³
（= 任务给的 ∫₀² π[(10+z)²−100]dz，镜像三角形同一总积分）。

V = 32000 − 1000π − 128π/3 = **28 724.366059857042** mm³

## 质心手算（ρ 加权，不是面积形心）

三角形面积形心 d̄ = 2/3 是错的（22 同款陷阱）；旋转体要用 ρ 加权：

∫∫ρ dA = ∫₀² [(12−d)²−100]/2 dd = 64/3
∫∫d·ρ dA = ∫₀² d·[(12−d)²−100]/2 dd = 14
z̄_去除(深度) = 14/(64/3) = 21/32 = 0.65625 → 绝对 z̄ = 5 − 21/32 = 139/32

cz = −(128π/3)(139/32)/V = −(556π/3)/V = **−0.020269963042944386**
x = y = 0（轴对称）。

## bbox / 拓扑

bbox = [80, 40, 10]；solids = 1，faces = 8（上下底面、4 侧壁、孔圆柱段、倒角圆锥），
与 22 同数。edges 两内核不同（b123d 17 vs smlibpy 15，seam 边计数差），不入 expected。

## chamfer 参数顺序（探针结论）

- build123d：独立函数 `chamfer(edges, length)` ✓；方法形式 `P.chamfer(2, rim)`
  会把 rim 传进 `length2` 槽而失败（签名 `(length, length2, edge_list, face)`）。
- smlibpy：`part.chamfer(edges, length)` ✓（文档明说孔口倒角可行，countersink 式）。
- 两内核 length 都是沿两面的 setback（对称 45°，直角边 2×2），语义一致。

## 容差

默认 1e-6 不放宽。实测：b123d 体积/质心与真值逐位一致（差 3e-16）；
smlibpy 体积 +1.19e-7 rel、质心 3.18e-7 abs（圆锥体积/矩积分的内核数值误差，
各在 1e-6 契约内，跨内核对照同样通过）。
