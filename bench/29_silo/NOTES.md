# 29 silo — 储料仓（三段接触融合）

## 设计意图

锥形料斗 + 圆筒 + 半球顶的三段轴对称堆叠，全部面接触融合（F-1 安全路径），
覆盖圆台方向语义（大端朝上）与"未旋转球 split 出半球"的跨内核等价。

## 尺寸

- 斗底圆台：r 20（上）→ 8（下），高 12，z ∈ [−12, 0]，大端朝上
- 筒体：R20 × 30，z ∈ [0, 30]
- 半球顶：R20，z ∈ [30, 50]（球心 (0,0,30)，split 保上侧）
- 三段在 z=0（r20 圆盘）与 z=30（r20 圆盘）全 face 接触融合 → 单一实体

## 探针结论

1. **Cone 方向**：两内核 `Cone(bottom_radius, top_radius, height)` 均为 bottom 在
   −Z、居中放置。探针 Cone(8,20,12)：下帽面积 64π @ z=−6、上帽 400π @ z=+6
   （两内核一致）→ 大端朝上 = `Cone(8, 20, 12)` 下移 6。
2. **半球用 split**（21_dome 模式）：球先移到 (0,0,30)，再在 z=30 split 保上侧。
   不移球直接对原点球 split z=30 → b123d 静默空壳 / smlibpy
   `ModelingError: nothing of the part lies above the plane`（FZ-7 split 空侧语义差，
   smlibpy 报错优于静默）。未旋转球 split 两内核逐位精确（FZ-9 只影响 Rot 过的球）。
3. **融合路径**：三段两两全 face 接触融合，属 F-1 安全清单（面接触融合）；
   实测两内核体积/质心/bbox 逐位一致。

## 体积手算

- 圆台 π·h/3·(r1² + r1·r2 + r2²) = π·12/3·(400 + 160 + 64) = 4π·624 = 2496π
- 筒体 π·20²·30 = 12000π
- 半球 (2/3)·π·20³ = 16000π/3

V = (7488 + 36000 + 16000)π/3 = **59488π/3 = 62295.6879255832 mm³**

## 质心手算

x = y = 0（轴对称）。圆台质心公式（从测量端半径 R0 起算，Rh 为另一端）：
z̄ = h(R0² + 2R0Rh + 3Rh²) / (4(R0² + R0Rh + Rh²))

- 圆台：从大端（z=0，R0=20）向下量 Rh=8：
  z̄ = 12·(400 + 320 + 192)/2496 = 12·912/2496 = 57/13 → **z = −57/13 = −4.3846153846**
  （交叉验证：从小端 r8 起算 12·(64+320+1200)/2496 = 7.6153846，−12 + 7.6153846
  = −4.3846154 ✓；两端起算一致）
- 筒体：V = 12000π，z = 15
- 半球：V = 16000π/3，z = 30 + 3R/8 = 37.5

ΣVz = π(−2496·57/13 + 180000 + 200000) = π(−10944 + 380000) = 369056π
z̄ = 369056π / (59488π/3) = 1107168/59488 = 34599/1859 = **18.611619150080690 mm**

## bbox / 拓扑

- bbox = [40, 40, 62]（x, y ±20；z −12..50）
- solids = 1，valid = true
- faces = 4（斗底圆盘 + 圆台侧面 + 筒柱面 + 半球面；两处接触界面融合后消失）

## 容差

默认 1e-6。两内核体积/质心逐位一致，无需放宽。
