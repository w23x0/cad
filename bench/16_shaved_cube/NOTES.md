# 16_shaved_cube — 斜面削角方块（split 倾斜面）

## 设计意图

40³ 立方体被平面 x+z=30（法向 (1,0,1)，45° 斜面）削去一个小角三棱柱
（直角边 10、高 40），再沿 Z 钻 Ø10 通孔。特征：**倾斜面 split**（两内核
keep 语义对齐：法向侧/Keep.TOP）、非轴对称真值。

> 探针注记：smlibpy `split(plane, keep="above")` 与 b123d
> `split(bisect_by, keep=Keep.TOP)` 都保留法向侧——本件取**另一侧**（大块），
> 两内核实测逐位一致（2000 小块 / 62000 大块互为补）。

## 体积手算

削去角柱：截面直角三角形直角边 10（顶点 (10,·,20),(20,·,10),(20,·,20)），
面积 50，沿 Y 长 40 → 2000。钻孔去除 π·5²·40 = 1000π（孔在 (0,0) 轴向 Z，
x²+y²≤25 处 x+z ≤ 25+20=... 最大 x+z = 5+20 = 25 ≤ 30，孔完全在大块内）：

V = 64 000 − 2 000 − 1 000π = **58 858.407346410204** mm³

## 质心手算

大块（削角后 62 000）质心：立方体质心 (0,0,0) 减去角柱（质心 (50/3, 0, 50/3)）：
c = (0·64 000 − 2000·(50/3))/62 000 = −100 000/186 000 = −0.5376344086021505（x、z 同）。
孔去除质心在 (0,0,·)，不动 x/z 比：

x = z = 62 000·(−0.5376344086021505)/V = **−0.5663308749954876**，y = 0

## bbox / 拓扑

bbox = [40, 40, 40]；solids = 1，faces = 8（6 盒面 + 斜切面 + 孔柱面），valid = true。

## 容差

默认 1e-6。两内核探针逐位一致（削角小块 2000.0000000000082 / 1999.999999999999，
互补大块同精度）。
